NodeVelture 기능정의서

AI와 함께 세계관을 만들고, 그 세계관 속 주인공이 되어 소설을 완성하는 협업 창작 플랫폼

최종 갱신: 2026-06-08 · AI휴먼 캠프 4기

1단계 작가 선택 → 세계관 설정
→
2단계 대화형 창작 (주인공 대사 → AI가 대사/나레이션 자동 구분, 메모로 설정 주입)
→
3단계 소설 변환
상태 ✅ 구현완료 🚧 진행중 📋 예정
우선순위 P0 MVP필수 P1 발표강화 P2 여유시
