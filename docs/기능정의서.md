# NodeVelture 기능정의서

> 최종 갱신: 2026-06-09 (16:00 강사님 스크럼 반영)
> 서비스 전체 기능을 분야·단계별로 정의한 문서입니다. 현황은 [PROJECT_STATUS.md](PROJECT_STATUS.md), 사용 흐름은 [사용자_시나리오.md](사용자_시나리오.md), 스크럼 기록은 [scrum/scrum.md](scrum/scrum.md) 참고.
> **AI 엔진: Groq(Llama 3.3) 기본 + Gemini 토글** (`LLM_PROVIDER`로 전환). E2E 전 체인 동작 확인됨.

## 🧭 서비스 코어 방향 (2026-06-09 확정)
- **척추(코어) = 진지한 창작 도구** — "혼자 쓰는 것보다 좋은 소설이 나온다"가 목적.
- **껍데기(진입로) = 엔터테인먼트** — 작가 페르소나·채팅·테마·아바타는 재미로 끌어들이는 수단.
- **우리만의 다리** = "캐릭터랑 놀듯 대화했더니 → 진짜 내 소설이 나온다." (character.ai엔 결과물 없음 / Sudowrite엔 캐릭터 놀이 없음)
- **차별점 3대 축 (강사님 6/9 요구에 직접 대응)**:
  1. **RAG(세계관 일관성)** — 길어져도 캐릭터·설정을 안 까먹음 → ChatGPT와의 결정적 차이 *(없으면 차별점 없음 — 강사님)*
  2. **AI 어시스턴트(창작 유도)** — 단순 호출이 아니라 다음 전개를 제안·유도
  3. **정량 근거** — "맨손 작성 vs 우리 서비스" 비교로 가치 입증

## 상태 범례
- ✅ 구현완료 · 🚧 진행중 · 📋 예정 · ❓ 검토필요

## 우선순위
- P0 (MVP 필수) · P1 (발표 강화·차별점) · P2 (여유 시)

## 1. 서비스 흐름 개요

```
[1단계] 작가 선택 → 세계관 폼 작성   (작가 페르소나 선택 / 세계관 태그 자동분류)
[2단계] 대화형 창작                  (사용자=주인공 / AI 응답 + 어시스턴트 유도 / RAG 일관성)
[3단계] 소설 변환 → 검수 → 읽기      (대화 로그 → 작가 문체 소설 → 일관성 검수 → read 화면)
```
