## 1. 서비스 흐름 개요

```
[1단계] 작가 선택 → 세계관 설정     (협업자=작가 페르소나)
[2단계] 대화형 창작                  (사용자=주인공 / AI=조연)
[3단계] 소설 변환                    (대화 로그 → 소설 문체)
```

## 3. MVP 범위 (3주 내 P0 우선)

**무조건 동작해야 하는 핵심 경로**
```
작가 선택 → 세계관 설정 → 채팅(작가/등장인물 모드) → 소설 변환
```

**P0 잔여 작업 (이 흐름을 막는 것)**
- F-CH-03: AI 응답 자동 구분 (대사/나레이션 단일 프롬프트)
- F-CH-04: AI 오프닝 상황 부여
- F-CH-08 연결: chats.py ↔ LLMRouter 통합 (SSE 포맷 통일)
- F-CH-11: 메모 설정 즉시 주입 연결
- F-NV-02: 소설 변환 실연결 (플레이스홀더 → generate_novel)
- F-NV-04: 소설 결과 화면
- F-WD-04: 나머지 작가 3인 세계관 페이지
- F-SY-04: 전역 에러 핸들링

**P1 발표 강화 (차별점)**
- F-CH-10: 세계관 일관성 RAG / 장기 기억 (🔥 최우선 차별점, RAG-lite 우선)
- F-CH-09: 조연 다중 동시 반응
- F-EV-01/03: 평가 리포트
