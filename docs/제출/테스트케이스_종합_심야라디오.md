## 4. ⭐ 캐릭터 지시사항 검증 (핵심)

- **2번** — 한 선배 대사에 **방송 멘트 + 옛 가요 언급** 둘 다 있으면 PASS
- **3번** — 민 기사 대사가 **단답 + 장비 비유** + 질문 없음이면 PASS
- **10번** — 여러 턴 뒤에도 한 선배가 **여전히 방송멘트/가요 유지** → 지시문이 컨텍스트에 계속 살아있다는 강력한 증거
