# MOS 평가 가이드 — 소설 결과물 (휴먼)

> 우리 서비스의 **소설 변환 품질**을 사람이 직접 채점하는 진짜 MOS. 자동 지표(`evaluate.py` 4축·LLM judge)가 **사람 감각과 같은 방향인지 교차검증**하는 게 목적.
> 샘플·정답키는 `backend/scripts/mos_sample_prep.py`로 생성 → `backend/data/mos_samples.md`(평가지)·`mos_answer_key.csv`(집계용).

---

## 1. 무엇을 재나
- **동일 입력 5개**를 각각 **우리(페르소나+문체 RAG) vs 베이스라인(같은 Gemini, 페르소나·문체층 제거)** 로 변환 → **10편**.
- 평가자는 **어느 게 우리/베이스라인인지 모른 채(블라인드)**, 순서도 셔플된 10편을 4축으로 채점.

## 2. 채점 4축 (각 1~5점) — `evaluate.py`와 동일 축
| 축 | 1점 | 5점 |
|---|---|---|
| **몰입도** | 안 읽힘 | 끝까지 읽고 싶음 |
| **문체 개성(작가다움)** | 밋밋·기계적 | 그 작가 톤이 뚜렷 |
| **캐릭터 일관성** | 인물이 붕괴 | 끝까지 그 인물 |
| **완성도** | 조각글 | 한 편으로 완결 |

## 3. 평가자
- **5명 이상.** 샘플을 만든 사람(개발자 본인)은 **제외** 또는 최소화.
- 어느 게 우리 시스템인지 **모른 채** 채점(블라인드). 정답키(`mos_answer_key.csv`)는 **절대 공유 금지**.

## 4. 구글폼 만드는 법 (10~15분)
1. 구글폼 새로 만들기 → 제목 "NodeVelture 소설 품질 평가(블라인드)".
2. 맨 앞 안내 섹션:
   > *"아래 10편의 짧은 소설을 읽고, 각 편을 4가지 기준으로 1~5점으로 평가해주세요. 어느 글이 어떤 시스템으로 만들어졌는지는 알려드리지 않습니다(공정한 평가를 위해). 정답은 없습니다, 읽은 느낌 그대로 매겨주세요."*
3. **샘플마다 1개 섹션** (총 10섹션). 각 섹션:
   - 섹션 설명에 `mos_samples.md`의 **샘플 텍스트를 그대로 붙여넣기**.
   - 그 아래 **객관식 그리드 1개**:
     - **행(4):** 몰입도 / 문체 개성 / 캐릭터 일관성 / 완성도
     - **열(5):** 1 · 2 · 3 · 4 · 5
     - "필수" 켜기.
   - (그리드 대신 '선형 배율 1~5' 질문 4개로 해도 됨)
4. 응답 → 스프레드시트로 받기(상단 '응답▸Sheets에 연결').

> 💡 그리드 1개/섹션이면 클릭이 빨라 평가자 피로↓ → 완주율↑.

## 5. 집계 (정답키로 조건 복원)
응답 시트 + `mos_answer_key.csv`를 합쳐서:
1. 각 (샘플×축) 점수에 정답키의 `condition`(ours/base)을 매칭.
2. **조건별 평균 ± 표준편차**(축별 + 4축 종합) 계산.
3. **우리 vs 베이스라인** 비교 + **평가자 간 편차**도 같이 본다(사람마다 갈리면 그게 정보).
4. ⭐ **자동지표와 방향 비교:** `evaluate.py`/`testset_eval`의 LLM-judge 점수와 **같은 방향인지** 대조 → "자동지표가 사람 감각과 어긋나지 않음"을 보이는 게 핵심.

예시 표(수집 후 채움):
```
            몰입  문체  캐릭터  완성  종합(20)
우리        _    _     _      _     _ ± _
베이스라인   _    _     _      _     _ ± _
평가자 n=_, 블라인드 10편
```

## 6. 발표 문구 (정직 프레임)
> *"자동 LLM-judge가 사람 느낌과 같은 방향인지 **5명 블라인드 MOS**로 교차검증했습니다. (결과)를 보면 — 자동지표와 (일치/괴리). 단발 변환이 GPT와 비슷했던 자동 결과를 사람도 (확인/반박)했습니다."*

- MOS의 목적은 *이기기*가 아니라 **"자동 평가가 사람 감각과 어긋나지 않는다"** 입증. 수치가 베이스라인과 비슷해도 *그 정합성*이 자체평가서 2-6의 빈칸을 메운다.
- ⚠️ **하지 말 것:** 사람 평가 없이 점수를 지어내는 것. 우리 발표의 무기는 "정직"이라 한 번이라도 꾸미면 다른 진짜 수치까지 의심받는다.
