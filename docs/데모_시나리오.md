# 데모(시연 영상) 시나리오 — 5분

> 작성: 2026-06-14 · 발표 시연 영상 기준. 관련: [사용자 시나리오](사용자_시나리오.md), [발표 정량근거](발표_정량근거.md)

## 0. 한 줄 컨셉 (영상 첫 멘트)

> **"ChatGPT로 소설을 쓰면 길어질수록 설정이 무너지고 내 문체가 안 남습니다. NodeVelture는 캐릭터와 *놀듯 대화*하면 그게 *진짜 내 소설*이 되고, *쓸수록 나를 압니다.*"**

전체를 관통하는 2개의 메시지를 시간순으로 보여준다:
1. **"놀듯 대화 → 진짜 내 소설"** (창작 파이프라인)
2. **"쓸수록 나를 아는 파트너"** (개인화 — 기억·문체·오답·취향)

## 2. 구간별 상세 (멘트 + 클릭)

### ① 오프닝 (0:00–0:25)
- **멘트:** 위 "한 줄 컨셉" 그대로.
- **화면:** 메인에서 작가 카드 위에 마우스 올려 **테마색이 바뀌는 것** 한 번 보여주기(시각적 임팩트).

### ② 작가·세계관 (0:25–1:00)
- **클릭:** 한여름(로맨스) 선택 → 화면이 **밝은 테마**로 전환되는 순간 강조.
- **세계관:** 폼은 **미리 채워두고** 빠르게 스크롤(장르·제목·주인공 이름·배경). 시간 절약 핵심 구간.
- **멘트:** "작가를 고르면 그 작가의 말투와 문체로 세계가 시작됩니다."

### ③ 대화형 창작 — 핵심 (1:00–2:20) ★가장 중요
- **AI 오프닝** 등장(상황 부여) → 주인공으로 대사 입력: 예) `"...설마 안 오는 건가."`
- **@등장인물 멘션:** `@민준` 으로 다른 인물 시점 대사 → 인물이 반응.
- **메모 주입(작가 기능):** 오른쪽 메모에 `사실 민준은 주인공의 첫사랑이다` 입력 → **다음 응답에 즉시 반영**되는 것 보여주기.
  - **이게 RAG 시연의 핵심:** "한 번 정한 설정이 사라지지 않고 계속 유지됩니다(기억·검수 RAG)."
- (옵션) **작가 리액션 자막**·**첫 문장 TTS 낭독** 한 번 들려주기 — 엔터테인먼트성.
- **멘트:** "주인공으로 연기하면서, 동시에 작가로 세계를 손봅니다. ChatGPT와 달리 설정이 무너지지 않아요."

### ④ 교정 · 오답노트(예측형) (2:20–3:20) ★차별점 1
- **일부러 틀리게 입력:** 예) `접근해야할까 고민좀` → 교정 결과 칩: `접근해야 할까 고민 좀 [띄어쓰기]`.
- **작가 톤 메모** 보여주기(백야면 건조하게, 한여름이면 다정하게) — **놀리지 않는 톤** 강조.
- **적용/넘기기** 한 번 시연(넘기기 = 고유명사 보호).
- **능동 경고(예측형):** 새 채팅/세션에 들어갈 때 뜨는 **"💡 자주 놓치는 것 — 너가→네가, 또 다시→또다시"** 카드.
  - **멘트:** "틀리면 고쳐주는 걸 넘어, 자주 틀리는 걸 **쓰기 전에 미리** 짚어줍니다. ChatGPT엔 없는 **영속적 개인 오답 기억**이에요."

### ⑤ 소설 변환 (3:20–4:15) ★차별점 2 (가장 큰 와우)
- **「채팅 종료」** 클릭 → "잠시만요" 변환 로딩(작가가 글 쓰는 연출).
- **읽기 화면** 진입: 완성된 **단편 소설**, 작가 문체, 제목·장르·글자수·예상 읽기, (장이 충분하면)목차.
- **내보내기(.txt)** 한 번 보여주기.
- **멘트:** "방금의 대화가 선택한 작가의 문체로 한 편의 소설이 됐습니다. 놀듯 대화한 게 진짜 내 작품이 된 거예요."

### ⑥ 마이페이지 · 비전 (4:15–5:00)
- **내 서재:** 그동안 쓴 작품 카드들 → 한 작품 클릭해 읽기로 이어짐(연속성).
- **취향 프로파일:** 9개 장르 점수 한 번 보여주기.
- **오답노트:** 누적 실수 + **항목별 ✕ 삭제** 시연(내가 관리).
- **클로징 멘트:**
  > "NodeVelture는 한 번 잘 써주는 도구가 아니라, **나와 끝까지 같이 쓰고 쓸수록 나를 아는 창작 파트너**입니다. 지금은 *반응형*, 다음은 취향 기반 *예측형 추천*으로 갑니다."

## 3. 촬영 전 준비 체크리스트 (필수)

- [ ] **백엔드 워밍업** — 녹화 직전 `GET /health` 한 번 호출해 **Cold Start 제거**(첫 요청 느림 방지). 채팅도 1턴 미리 돌려두기.
- [ ] **시드 데이터** — 데모용 세션을 **미리 몇 턴 진행**해 두면 ⑤ 소설 변환이 빠르고 결과가 좋다. 빈약한 대화로 변환하면 본문이 짧아 어색.
- [ ] **읽기용 백업 작품** — 본문이 **풍부한 완성작 1개**를 미리 준비(라이브 변환이 느릴 때 바로 이걸로 전환).
- [ ] **오답노트 데이터** — 능동 경고가 뜨려면 **2회 이상 틀린 표기**가 있어야 함(데모 계정에 미리 쌓아두기).
- [ ] **계정·테마** — 로그인 된 상태, 한여름(밝은 테마)로 시작(화면이 예쁘고 가독성↑).
- [ ] **네트워크/소리** — TTS 들려줄 거면 볼륨 확인, 안정적 회선.
- [ ] **해상도** — 1080p 이상, 글자 잘 보이게 브라우저 확대 100~110%.

## 4. 피해야 할 함정 (NG 컷)

- ❌ **Cold Start 노출** — 첫 응답이 8초씩 걸리는 장면. (→ 사전 워밍업)
- ❌ **빈 화면** — 본문 0자 소설, 빈 서재, 빈 오답노트. (→ 시드 데이터)
- ❌ **라이브 변환 장시간 대기** — 10초 넘어가면 백업 완성작으로 컷 전환.
- ❌ **교정 톤 사고** — 혹시 옛 리비전이면 톤이 셀 수 있음. 최신 배포(조롱 금지 가드 포함)인지 확인.
- ❌ **공유 계정 데이터 혼선** — 데모 계정에 다른 사람 흔적이 보이지 않게 정리.

## 5. 짧은 버전(3분)으로 줄여야 하면

①②를 합쳐 30초, ③ 60초, ⑤ 60초, ⑥ 30초로 압축하고 **④(교정·오답)** 를 30초로 줄인다. ③(메모 주입=RAG)와 ⑤(소설 변환)는 **절대 빼지 말 것** — 가장 큰 차별점.

## 6. 차별점 요약(발표 슬라이드 1장용)

| | ChatGPT | NodeVelture |
|---|---|---|
| 장기 일관성 | 길어지면 무너짐 | 기억 RAG로 설정 유지 |

| 결과물 | 채팅 덩어리 | **대화→단편 소설 변환** |
| 개인화 | 휘발 | 취향·오답이 **내 것으로 누적** |
