## 0. 한 줄 컨셉 (영상 첫 멘트)

> **"ChatGPT로 소설을 쓰면 길어질수록 설정이 무너지고 내 문체가 안 남습니다. NodeVelture는 캐릭터와 *놀듯 대화*하면 그게 *진짜 내 소설*이 되고, *쓸수록 나를 압니다.*"**

관통 메시지 2개를 시간순으로:
1. **"놀듯 대화 → 진짜 내 소설"** (창작 파이프라인 — 기억·검수·문체·변환)
2. **"쓸수록 나를 아는 파트너"** (개인화 — 오답·취향)

## 2. 구간별 상세 (멘트 + 클릭)

### ① 오프닝 (0:00–0:30)
- **멘트:** 위 "한 줄 컨셉" 그대로.
- **화면:** 메인에서 작가 카드 위에 마우스 올려 **테마색 전환** 한 번(시각 임팩트).

### ② 작가·세계관 (0:30–1:15)
- **클릭:** 한여름(로맨스) 선택 → **밝은 테마 전환** 강조.
- **세계관:** 폼은 **미리 채워두고** 빠르게 스크롤(제목·장르·배경·**주인공 이름·등장인물**). ⚠️ **등장인물(조연)을 반드시 등록**해야 ③의 @멘션 드롭다운에 뜬다.
- **멘트:** "작가를 고르면 그 작가의 말투·문체로 세계가 시작됩니다."

### ③ 대화형 창작 — 핵심 (1:15–3:15) ★가장 중요
- **AI 오프닝** 등장(상황 부여) → 주인공으로 대사: 예) `"...설마 안 오는 건가."`
- **@등장인물 멘션 — 올바른 흐름**(중요, 한 줄에 같이 치지 말 것):
  1. 입력창에 **`@`** 입력 → **등록된 등장인물 드롭다운**이 뜸
  2. 인물(예: 민준) **클릭/Enter** → 입력창 위 **`@민준` 화자 칩** 생김 + 입력창 비워짐
  3. **그다음** 민준의 대사를 입력 → 그 턴은 **민준이 말하는 것**으로 처리
  - ⚠️ `@민준 안녕` 처럼 공백+문장을 한 줄에 치면 드롭다운이 닫힘. **선택 후 입력**이 정석.
- **메모 주입(작가 기능):** 오른쪽 메모에 `사실 민준은 주인공의 첫사랑이다` → **다음 응답에 즉시 반영**.
  - **RAG 시연 핵심:** "한 번 정한 설정이 안 사라집니다(기억·검수 RAG)."
- **화자 고정 강조:** 대화가 이어져도 **누가 말하는지(주인공/등장인물)가 안 흔들림** — 화자 검증(L1)+프롬프트 규칙(L2) 2겹.
- (옵션) **작가 리액션 자막**·**첫 문장 TTS 낭독** 한 번 — 엔터테인먼트성.
- **멘트:** "주인공으로 연기하면서 작가로 세계를 손봅니다. 설정도, 화자도 안 무너져요."

### ③-2 💡 문장 추천 (말투 기반) ★핵심
*"뭐라고 써야 할지 막막한" 백지 공포를 직접 해결하는 기능. 시연에서 꼭 보여줄 것.*
- 입력창 옆 **💡 버튼**을 누른다(또는 응답 후 자동으로 추천 칩이 뜸).
- **추천 대사 칩 2~3개**가 뜬다 → 그중 하나를 **클릭하면 입력창에 그대로 채워짐** → 살짝 다듬어 전송.
- **차별점 — 말투 개인화:** 마이페이지에서 내 **말투(voice 프로파일)** 를 설정해두면, 추천이 **내 말투로** 나온다(반말/존댓말·문장 길이·이모지 습관 반영). 없으면 장면 맥락 기반 일반 추천.
- **멘트:** "다음에 뭐라고 쓸지 막막할 때, AI가 **내 말투 그대로** 다음 대사를 추천해줍니다. 백지에서 시작하는 부담이 사라져요 — 이게 '쓸수록 나를 안다'의 또 다른 얼굴이에요."
- ⚠️ 데모 팁: 말투 추천을 제대로 보여주려면 **voice 프로파일을 미리 설정**해 두기(없으면 일반 추천만 떠서 임팩트↓).

### ③-3 엔터테인먼트 — "껍데기"의 재미
*진지한 창작 도구(척추) + 노는 재미(껍데기)를 보여주는 비트.*
- **작가 리액션 자막:** 내가 대사를 보내면 작가 아바타 위에 **짧은 반응 자막**이 뜬다(작가×감정 풀에서 선택). 작가가 같이 노는 느낌.
  - (참고: 자막 스타일은 `chat/ui.css`의 `.author-reaction-subtitle`, 렌더는 `chat/ui.jsx`의 `{reaction && ...}`)
- **TTS 음성 낭독:** 작가별 목소리로 **첫 문장을 읽어준다**(ElevenLabs). 멀티모달 가산 영역.
  - ⚠️ ElevenLabs가 **클라우드 IP 차단(401)** 이슈 → **로컬/키 동작 환경**에서만 재생됨. 데모 환경 미리 확인, 안 되면 이 컷 생략.
- **#취향저격 AI:** 입력창 위 태그에서 **#취향저격ai** → 내 취향 기반으로 작가가 방향을 추천. "예측형 추천" 로드맵의 맛보기.

### ③-4 검수 RAG — "설정 모순을 잡는가" ★차별점 3축의 마지막
*기억·검수·문체 중 '검수'. 데모에서 차별점 3축을 완성하는 비트.*
- **무엇:** 새 문장이 확립된 설정과 모순되면 **독자 입장에서 잡아냄**. 예) "민준=잠입 형사"인데 "민준은 외과 의사였다" → 🚨 모순 탐지(설정:형사 / 충돌:의사 `[high]`).
- **시연 방법:** 현재 **채팅 UI엔 미노출**이라 라이브로 못 보여줌 → **정량근거 슬라이드** 또는 `python -m scripts.consistency_demo` **터미널**로 보여준다.
- **멘트:** "독자 입장에서 '어, 아까 형사라며?'를 AI가 대신 잡아줍니다. 지금은 백엔드에서 돌고, **화면에 띄우는 게 다음 로드맵**입니다." (정직 + 로드맵 = 신뢰도↑)

### ④ 교정 · 오답노트(예측형) (3:15–4:15) ★차별점
- **일부러 틀리게:** 예) `접근해야할까 고민좀` → 교정 칩: `접근해야 할까 고민 좀 [띄어쓰기]`.
- **작가 톤 메모**(놀리지 않는 톤) → **적용/넘기기**(넘기기=고유명사 보호) 한 번.
- **능동 경고(예측형):** 재진입 시 **"💡 자주 놓치는 것 — 너가→네가, 또 다시→또다시"** 카드.
  - **멘트:** "틀리면 고치는 걸 넘어, 자주 틀리는 걸 **쓰기 전에 미리** 짚어줍니다. ChatGPT엔 없는 **영속적 개인 오답 기억**."

### ⑤ 소설 변환 (4:15–5:15) ★가장 큰 와우
- **「채팅 종료」** → "잠시만요" 변환 로딩(작가가 글 쓰는 연출).
- **읽기 화면**: 완성된 **단편 소설**(작가 문체) · 제목·장르·글자수 · (충분하면)목차 · **상단 진행률 바 고정**.
- **멘트:** "방금 대화가 선택한 작가 문체로 한 편의 소설이 됐습니다. 놀듯 대화한 게 진짜 내 작품이 된 거예요."

### ⑥ 삽화 생성 (5:15–6:15) — NEW
- 읽기 화면 우상단 **✨ 삽화 생성** → 장면 추천 중 하나 선택(또는 직접 묘사) → 스타일/분위기 선택.
- **Vertex Gemini 2.5 Flash Image**로 생성(약 10여 초 — **저장 중 표시** 있음) → **저장하기** → 내 삽화에 보관.
- **멘트:** "텍스트를 넘어, 내 소설의 한 장면을 삽화로 만듭니다. fal.ai에서 Vertex로 엔진을 바꿔 IP차단·비용 문제를 해결했어요."
- ⚠️ 생성 시간 있음 → 미리 한 장 만들어둔 걸 보여주거나, 로딩을 멘트로 메우기.

### ⑦ 마이페이지 · 비전 (6:15–7:00)
- **내 서재:** 쓴 작품 카드 → 한 작품 클릭해 읽기로 이어짐(연속성).
- **취향 프로파일** 한 번 + **오답노트**(누적 + **✕ 삭제**, 내가 관리).
- **클로징:**
  > "NodeVelture는 한 번 잘 써주는 도구가 아니라, **나와 끝까지 같이 쓰고 쓸수록 나를 아는 창작 파트너**입니다. 지금은 *반응형*, 다음은 취향 기반 *예측형 추천*으로 갑니다."

## 3. 촬영 전 준비 체크리스트 (필수)

- [ ] **백엔드 워밍업** — 녹화 직전 `GET /health` + 채팅 1턴·삽화 1장 미리 돌려 **Cold Start 제거**.
- [ ] **시드 데이터** — 데모 세션을 **미리 몇 턴 진행**(③/⑤ 변환이 빠르고 결과 좋게).
- [ ] **등장인물 등록 확인** — @멘션이 뜨려면 세계관에 **조연 인물이 등록**돼 있어야 함.
- [ ] **읽기용 백업 작품 + 삽화 1장** — 라이브 변환/삽화가 느릴 때 바로 전환.
- [ ] **오답노트 데이터** — 능동 경고용 **2회 이상 틀린 표기** 미리 쌓기.
- [ ] **voice(말투) 프로파일 설정** — ③-2 문장 추천을 *내 말투로* 보여주려면 마이페이지에서 말투를 미리 설정(없으면 일반 추천만).
- [ ] **계정·테마** — 로그인 상태, 한여름(밝은 테마)로 시작.
- [ ] **네트워크/소리** — TTS 볼륨, 안정 회선.
- [ ] **해상도** — 1080p+, 브라우저 확대 100~110%.

## 4. 피해야 할 함정 (NG 컷)

- ❌ **Cold Start 노출** — 첫 응답/삽화가 오래 걸리는 장면. (→ 사전 워밍업)
- ❌ **빈 화면** — 본문 0자 소설, 빈 서재/오답노트. (→ 시드 데이터)
- ❌ **@멘션 오용** — `@이름 문장`을 한 줄에 치기. (→ `@`→선택→대사 입력 순서로)
- ❌ **등록 안 된 새 인물 즉석 등장** — "낯선 손님" 식으로 미등록 인물을 대화에 끌어들이면 화자/정체성이 꼬임. **세계관에 등록된 인물 안에서** 진행.
- ❌ **라이브 변환/삽화 장시간 대기** — 10초+면 백업본으로 컷.
- ❌ **공유 계정 데이터 혼선** — 데모 계정에 남의 흔적 안 보이게 정리.

## 5. 축약 버전

- **5분**: ⑥(삽화)를 30초로 줄이거나 미리 만든 1장만 노출, ③·⑤는 유지.
- **3분**: ①②를 30초, ③ 60초, ⑤ 60초로 압축, ④·⑥·⑦을 최소화. **③(메모=RAG)·⑤(변환)는 절대 빼지 말 것** — 가장 큰 차별점.
