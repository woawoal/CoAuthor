## 한 줄 현황

## ③ AI 응답 엔진 — 데모 대상  · 브리핑: **jyj · 동완**
**상태: 핵심 완료 · 시연 가능**
- **엔진: Vertex AI Gemini 2.5 Flash-lite** — Groq의 한자/일본어 누수를 해결, **응답 8s → 2s**(thinking off + flash-lite)
- **멀티엔진 파이프라인**(`llm.py`): `.env` 한 줄로 Provider 전환(Gemini/Groq/OpenAI) + n키 순환 · 429 분기 · 쿨다운 · 백오프
- **페르소나 응답**: 작가 4인 시스템 프롬프트로 문체별 대사/서술 분리 응답(동완)
- 진행중: 팀 공통 엔진 표준화(현재 Vertex가 가장 깨끗·빠름 → 수렴 중)
- 🎬 데모: 같은 입력 → 작가별 다른 문체 응답 / 엔진 토글 / 응답 속도

## ④ 백엔드 및 통합 — 데모 대상  · 브리핑: **jyj · 가연**
**상태: 완료 · 시연 가능**
- **FastAPI + 실제 LLM 호출(모의 아님)**, 인프로세스 **E2E 스모크 9/9**
- **저장소: PostgreSQL = Neon(클라우드 공용, 가연 셋업) + Redis = Upstash** — Dialogue/Session/Novel/ApiLog 적재 확인
- **차별점 백엔드 = RAG 3종**: ①세계관·줄거리 기억 검색(`memory.py`) ②설정 일관성 검수(`consistency.py`) ③작가 문체 few-shot(`style.py`)
- 어시스턴트 `/suggest`(다음 전개 제안) · 작가 메모 `/memo` API
- 비용/성능: 토큰 분석 API(모델·세션별), 증분 요약 · 컨텍스트 윈도우(최근 10턴), thinking off
- 🎬 데모: E2E 스모크 실행 / RAG 데모(6턴 전 비밀 정확 회상, 형사↔의사 모순 탐지)

## ⑤ 클라이언트 — 데모 대상  · 브리핑: **가은 · 건혁**
**상태: 핵심 연동 완료 · 신규기능 연결 진행중**
